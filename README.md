# 100x Data Engineer Assessment - Abhay Rahangdale

## Overview

This repository contains the solution for the 100x Data Engineer assessment. It demonstrates ETL from raw JSON data into a normalized MySQL database.

## Dataset

- `data/raw.json` : Contains property information including address, price, HOA fees, rehab estimates, and valuations.
